# Generic FMEA Template (fallback)

Use this when the item doesn't clearly match one of the domain-specific templates. It provides the structure without pretending to know the specific failure modes of an unfamiliar product or process — the failure chains here are placeholders meant to be filled in with the user's actual information, not illustrative examples to fall back on.

Works for either DFMEA or PFMEA; adapt the structure/function labels accordingly (structure tree + P-Diagram for DFMEA, process flow + 4M for PFMEA).
